# Мониторинг ОКН

Система мониторинга объектов культурного наследия (ОКН) для городов Свердловской области.

## О проекте

Некоммерческий проект общественной организации ВООПИК (Всероссийское общество охраны памятников истории и культуры) в Свердловской области. Волонтеры фотографируют объекты культурного наследия и фиксируют их состояние, заполняя специальные анкеты.

## Компоненты системы

### 🌐 Веб-приложение ([`web/`](web/))
Интерактивная веб-страница для визуализации статистики мониторинга:
- Отображение объектов по временным периодам
- Статистика по состояниям объектов
- Интерактивные карточки с детальной информацией
- Интеграция с данными из Google Таблиц

**Статус:** ✅ В разработке (версия 1.0)

**Запуск:**
```bash
cd web && python -m http.server 8000
```

### 🤖 Telegram бот ([`bot/`](bot/))
Автоматическая публикация анкет волонтеров в канал [@monitoringokn](https://t.me/monitoringokn):
- Публикация новых анкет с фотографиями
- Автоматическое сжатие изображений
- Ежедневные сводки о проделанной работе
- Обработка данных из Google Таблиц

**Статус:** ✅ Работает в продакшене

**Запуск:**
```bash
cd bot && pip install -r requirements.txt && python index.py
```

### 🗂️ Старая версия ([`web_old/`](web_old/))
Первая версия веб-приложения. Сохранена для справки по методам работы с Google Sheets API.

**Статус:** ⚠️ Только для справки, не использовать для разработки

## Быстрый старт

### Для разработчиков веб-приложения
```bash
# Клонировать репозиторий
git clone <repository-url>
cd monitoring

# Запустить новое веб-приложение
cd web
python -m http.server 8000
# Открыть http://localhost:8000
```

### Для разработчиков бота
```bash
# Установить зависимости
cd bot
pip install -r requirements.txt

# Настроить .env файл (см. .env.example)
cp .env.example .env
# Отредактировать .env с токенами и ID

# Запустить бота
python index.py
```

## Технологии

### Веб-приложение
- HTML5, CSS3 (Grid, Flexbox)
- Vanilla JavaScript (без фреймворков)
- Google Sheets API
- SVG иконки

### Telegram бот
- Python 3.8+
- python-telegram-bot
- Google Sheets API v4
- Google Drive API
- Pillow для обработки изображений

## Состояния объектов

Цветовая кодировка в приложении:
- 🟢 **Хорошее** - объект в отличном состоянии
- 🟡 **Нормальное** - требует внимания
- 🟠 **Плохое** - требует ремонта
- 🔴 **Руины** - критическое состояние
- ⚫ **Не существует** - объект утрачен
