# Техническое требование: Система визуализации временной шкалы ОКН

## 1. Цель проекта

Создание нового интерфейса системы мониторинга объектов культурного наследия с визуализацией временной шкалы, полностью соответствующего дизайн-макетам.

**Ключевые задачи:**
- Реализовать современный интерфейс с временной шкалой по годам постройки
- Обеспечить интерактивные всплывающие окна с детальной информацией об объектах
- Создать адаптивный дизайн с высокой производительностью для 131+ объекта
- Сохранить совместимость с существующим источником данных

## 5. Техническая реализация

### 5.1 Алгоритм группировки данных

**Шаг 1: Группировка по городам**
```javascript
// Группировка всех объектов по городам
function groupObjectsByCity(objects) {
    const cities = {};

    objects.forEach(obj => {
        const cityName = obj.city || 'Неизвестный город';
        if (!cities[cityName]) {
            cities[cityName] = {
                name: cityName,
                objects: [],
                count: 0
            };
        }
        cities[cityName].objects.push(obj);
        cities[cityName].count++;
    });

    // Сортировка городов по убыванию количества объектов
    return Object.values(cities).sort((a, b) => b.count - a.count);
}
```

**Шаг 2: Группировка по временным периодам внутри города**
```javascript
// Функция группировки объектов одного города по временным периодам
function groupCityObjectsByTimePeriod(cityObjects) {
    const periods = {
        'before-1800': { label: 'до 1800 года', objects: [] },
        '1800-1850': { label: '1800-1850', objects: [] },
        '1850-1880': { label: '1850-1880', objects: [] },
        '1880-1900': { label: '1880-1900', objects: [] },
        '1900-1940': { label: '1900-1940', objects: [] },
        'after-1940': { label: 'после 1940', objects: [] }
    };

    cityObjects.forEach(obj => {
        const year = parseInt(obj.year) || 0;
        const period = determinePeriod(year);
        if (periods[period]) {
            periods[period].objects.push(obj);
        }
    });

    return periods;
}

// Определение периода по году
function determinePeriod(year) {
    if (year < 1800) return 'before-1800';
    if (year >= 1800 && year < 1850) return '1800-1850';
    if (year >= 1850 && year < 1880) return '1850-1880';
    if (year >= 1880 && year < 1900) return '1880-1900';
    if (year >= 1900 && year < 1940) return '1900-1940';
    return 'after-1940';
}
```

**Полный процесс обработки:**
```javascript
// Основная функция обработки данных
function processData(rawObjects) {
    // 1. Группировка по городам (с сортировкой по количеству)
    const cities = groupObjectsByCity(rawObjects);

    // 2. Для каждого города - группировка по периодам
    cities.forEach(city => {
        city.periods = groupCityObjectsByTimePeriod(city.objects);
    });

    return cities;
}
```
