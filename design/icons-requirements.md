# Техническое задание на иконки зданий
## Система мониторинга ОКН г. Каменск-Уральский

### Цель
Создать набор SVG иконок для визуального представления типов объектов культурного наследия в веб-приложении мониторинга.

### Функционал иконок
- Визуальная идентификация типа здания на карточках объектов
- Быстрое распознавание архитектурного типа пользователями
- Унифицированное представление в интерфейсе

### Технические требования

**Формат и размеры:**
- Формат: SVG
- Размер: 24×24px (векторный, масштабируемый)
- Обводка: 1.5px
- Заливка: отсутствует (только контур)
- Цвет: currentColor (наследуется от родителя)

**Стиль:**
- Минималистичный line-art стиль
- Четкие, узнаваемые силуэты
- Единообразная толщина линий
- Отсутствие мелких деталей (читаемость на малых размерах)

### Требуемые иконки

#### Существующие иконки (требуют перерисовки)

1. **bridge.svg** - Мост
   - Арочная конструкция с опорами
   - Характерный силуэт моста через водоем
   - Акцент на архитектурные элементы (арки, перила)

2. **church.svg** - Церковь/храм
   - Крестообразный план с куполом
   - Колокольня или звонница
   - Характерные элементы православной архитектуры

3. **palace.svg** - Дворец/особняк
   - Симметричный фасад с центральным входом
   - Декоративные элементы (колонны, портик)
   - Многоэтажная структура с парадным видом

4. **house.svg** - Жилой дом
   - Одно-двухэтажное здание
   - Скатная крыша с трубой
   - Простая прямоугольная форма с окнами

5. **highrise.svg** - Многоэтажный дом
   - Высотное здание с множеством окон
   - Повторяющийся ритм окон по фасаду
   - Плоская или скатная крыша

6. **gate.svg** - Ворота
   - Арочный проход в стене или заборе
   - Декоративные элементы обрамления
   - Характерные для усадебной архитектуры

7. **barn.svg** - Хозяйственная постройка
   - Простое прямоугольное здание
   - Двускатная крыша
   - Минимум декоративных элементов

8. **ensemble.svg** - Архитектурный ансамбль
   - Группа из 2-3 зданий разной высоты
   - Единый архитектурный стиль
   - Композиционное единство

#### Новые иконки для уральского региона

9. **factory.svg** - Промышленное здание
   - Силуэт с трубами и заводскими корпусами
   - Характерно для индустриального наследия Урала

10. **tower.svg** - Башня/водонапорная башня
    - Высокая цилиндрическая конструкция
    - Типично для промышленной архитектуры

11. **monument.svg** - Памятник/монумент
    - Обелиск или скульптурная композиция
    - Мемориальные объекты

### UX/UI требования

**Читаемость:**
- Иконки должны быть понятны без подписей
- Различимы при размере 16px
- Контрастны на светлом и темном фоне

**Консистентность:**
- Единый визуальный язык со существующими иконками
- Одинаковая толщина обводки
- Сопоставимый уровень детализации

### Готовность

**Критерии приемки:**
- [ ] Все 11 иконок в формате SVG
- [ ] Размер файла каждой иконки < 2KB
- [ ] Валидный SVG код без ошибок
- [ ] Визуальная консистентность с существующими иконками
- [ ] Читаемость на размере 16px
- [ ] Работа с currentColor

**Поставка:**
- Отдельные SVG файлы с указанными именами
- Все иконки в едином стиле
- Оптимизированный код без лишних элементов

### Примеры использования
Иконки будут использоваться в карточках объектов рядом с названием и статусом состояния. Пользователь должен сразу понимать тип здания при беглом просмотре списка объектов наследия.
